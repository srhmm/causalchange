### API reference

---

| Object | Purpose |
|---|---|
| `Topic` | Convenience estimator for TOPIC on one tabular dataset. |
| `Linc` | Convenience estimator for LINC on multi-context tabular data. |
| `SpaceTime` | Convenience estimator for temporal and multi-context temporal discovery. |
| `CausalChange` | General estimator for advanced/custom configurations. Use `fit(X)`, then inspect `graph_`, `result_`, `topological_order_`, `history_`, and temporal attributes. |
